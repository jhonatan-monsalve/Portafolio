## 👨‍💻 Sobre el Proyecto

Este repositorio contiene la arquitectura y el código fuente de mi portafolio profesional. El sitio fue desarrollado con un enfoque en accesibilidad, diseño adaptable (responsive) y código limpio y modular, funcionando como carta de presentación digital frente a reclutadores y clientes.

### Estructura del Sitio:
* **`index.html`**: Presentación general, propuesta de valor y canales de contacto rápido.
* **`about.html` / Sobre mí**: Trayectoria profesional, motivación y filosofía de trabajo orientada al rigor operativo.
* **`curriculum.html`**: Desglose detallado de experiencia laboral (más de 12 años en entornos de misión crítica y monitoreo), formación técnica y competencias informáticas.

---

## 🛠️ Stack Tecnológico Utilizado

* **Frontend:** HTML5 semántico, CSS3 modular (diseño adaptable a móviles y escritorio) y JavaScript.
* **Despliegue & Hosting:** GitHub Pages con control de versiones integrado.
* **Buenas Prácticas:** Optimización de carga, maquetación responsiva y estructura de navegación intuitiva.

---

## 💻 Mis Competencias Técnicas Principales

* **Sistemas & Soporte IT:** Mantenimiento microinformático, diagnóstico de hardware/software, redes locales (TCP/IP), control de accesos y protocolos de seguridad (ISO/IEC 27001).
* **Desarrollo & Automatización:** Fundamentos sólidos en Python, Java, JavaScript, consultas SQL y consumo de APIs REST / Webhooks.
* **Control de Versiones:** Flujos de trabajo con Git y GitHub.
